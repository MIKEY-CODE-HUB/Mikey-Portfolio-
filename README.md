# MIKEY — Architectural 3D Portfolio

An immersive, continuous 3D personal portfolio and spatial architecture experience exploring computer science, software engineering, systems design, and philosophical paradox.

## Features

- **Continuous 3D Spatial Architecture**: Built with Three.js, React 19, and Tailwind CSS.
- **Dynamic Chapter Navigation**: Smooth cinematic camera movements and spatial transitions across 5 chapters.
- **Procedural Shaders & Sound**: Custom procedural geometries, typography wordmarks, and ambient atmosphere.
- **Fast Production Builds**: Vite-powered client build with SPA routing for seamless Vercel deployment.

## Getting Started

### Prerequisites

- Node.js (v18+)
- npm or bun

### Local Development

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
```

## Deployment

Configured for immediate deployment on Vercel with Vite framework preset and SPA routing (`vercel.json`).
